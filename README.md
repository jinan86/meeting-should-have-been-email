## The entry

> The calendar invite had an agenda, a purpose, and a clear decision to make, so we spent fifty minutes confirming none of us had opened it.

138 characters, one line, plain text.

## How it works

`main.py` (Python 3, stdlib only, fully deterministic) writes the entry
to `/output/entry.txt`. It self-checks the competition gate before writing:
UTF-8, exactly one line, 1–200 characters, not only whitespace.

```bash
python3 main.py
cat /output/entry.txt
```

Running it twice produces byte-identical output
(sha256 `7aafa153e7286d2a1012c2608c57800fdd3fbaaf9bbc3dc4f60c0c47e4aa5228`).
